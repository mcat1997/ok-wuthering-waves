# 固定队伍专属战斗轴

## 用户故事

- 作为维护自动战斗角色逻辑的开发者，我希望能把某个固定队伍的出手顺序集中写在一处，而不是把队伍配合散落到多个角色类里。
- 作为调试特定队伍表现的人，我希望没有命中专属轴时仍然沿用默认自动战斗，而不是让新逻辑影响所有队伍。
- 作为新增队伍支持的人，我希望第一版先用代码配置验证少量队伍，而不是一开始就设计普通用户可编辑的复杂配置界面。

## 为什么需要

现有自动战斗能处理通用角色行为和换人优先级，但固定队伍常常需要更具体的出手节奏。继续把这些特殊规则写进角色类，会让“这套队伍到底怎么跑”变得难追踪，也容易影响其他队伍。

## 怎么解决

给自动战斗增加一个可选的队伍级 profile：识别到指定角色组合后，开发者写的 profile 可以接管必要的动作和换人顺序；没有匹配或执行失败时，系统回到默认自动战斗。

## 边界

- 不面向普通用户提供配置文件或 GUI。
- 不做无限自由的脚本语言。
- 不要求一次覆盖所有队伍；第一版只验证少数队伍或测试示例。
- 不替代角色自己的基础动作能力，队伍 profile 只负责队伍层的编排。
